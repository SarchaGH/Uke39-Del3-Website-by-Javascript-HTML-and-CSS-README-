## Explore Thailand website

### 1. Project Overview
Hello! in this project i designed to make the website that explore **Thailand** my homeland. 
I using Javascript, HTML, and CSS to manage and decollated my own website.
In this website will show 6 region of Thailand (*Central, Northern, Northeast/Isan, Eastern, Western and Southern*).

### 2. Features 
- The common information about Thailand and link that send user to **Wikipedia** to read more about Thailand
- Light and dark mode button, this button help user to change them of the website between Light and Dark mode by clicking on the button
- Region button, those button will bring user to the **Google Map** of the region that user clicking it also hover in this button  
- Alert! I made the easy future that greeting the user when entering the website
